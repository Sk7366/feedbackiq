# FeedbackIQ
### AI-Powered Customer Feedback Analytics

FeedbackIQ is a Python-based customer feedback analytics dashboard that transforms unstructured customer reviews into meaningful insights and actionable business recommendations.

### Features
- Upload customer feedback through CSV files.
- Clean and preprocess text data.
- Analyze customer sentiment using VADER.
- Automatically categorize customer feedback.
- Identify the most concerning feedback categories.
- Extract frequently discussed keywords.
- Generate actionable business recommendations.
- Visualize insights through an interactive dashboard.
- Export analyzed feedback as a CSV file.

### Tech Stack
- Python
- Streamlit
- Pandas
- VADER Sentiment Analysis
- Plotly

### Run Locally

```bash
git clone YOUR_REPOSITORY_URL
cd feedbackiq

python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

### Project Goal
To help businesses understand customer opinions, identify recurring issues, monitor customer sentiment, and make data-driven decisions through feedback analytics.
